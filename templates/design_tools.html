This is a first-principles geometric calculation, not a Wavin-verified source. It replaces a simplified two-box-difference method with an exact stepped-void volume: each step is a sloped riser topped by a flat bench, with the topmost riser reaching grade directly (no bench above ground level). Benching is not permitted in Type C soil per OSHA Appendix B. OSHA Table B-1 sets specific maximum bench height/width limits for Type A/B soil — this tool does not enforce those specific dimensions; verify your chosen step height and bench width against Table B-1 yourself.

Screens the minimum horizontal setback between an adjacent foundation, footing, or retaining wall and the AquaCell tank, so lateral load from that structure does not project down onto the crates. Based on a single soil load-influence wedge rising from the tank base at the internal shear angle. Method: L min = (H2 − H1) × tan(90° − a), equivalently (H2 − H1) ÷ tan(a). Internal Wavin method — there is no standalone Wavin drawing number for this check. It is a geometric screen only, not a geotechnical or structural design.

Angle of the load-influence wedge from horizontal. Default 45°. Use a project-specific value from the geotechnical report when available — a lower angle gives a larger required setback (e.g. 30° → run = 1.73× the depth difference; 45° → run = 1.00×).

This calculator provides preliminary, conceptual estimates only and is not a stamped engineering design. Base, cover, and perimeter stone depths/widths, void ratios, and tank geometry are all independently adjustable inputs — verify every value against project-specific plans. The Engineer of Record is solely responsible for confirming all design parameters, site conditions, and final storage volumes.

Note on tank footprint: AquaCell units interlock in a fixed module grid (1.9685 ft × 3.937 ft per crate) and can only be assembled in whole-crate increments. Enter your known/measured footprint below — the calculator automatically "snaps" it down to the nearest whole number of crates in each direction and uses that snapped footprint (not your raw input) for every storage calculation.
